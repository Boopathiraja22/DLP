# Duty List PDF Parser

Generates individual PDF files per faculty from the Consolidated Duty List PDF.

## Steps to get the EXE (no Python needed)

1. Create a free account at https://github.com
2. Create a new repository and upload all files in this folder
3. Go to Actions tab → Build EXE → Run workflow
4. Wait ~2 minutes → Download DutyListParser-Windows artifact
5. Unzip → Run DutyListParser.exe on any Windows PC

## Using the app

1. Browse → select Duty List PDF
2. Browse → choose output folder  
3. Click Generate PDFs
